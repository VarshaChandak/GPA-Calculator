# GPA Calculator

A sleek, dark-themed GPA calculator web app with smooth animations and a clean UI. Easily add your courses, input grades and credits, and get your GPA calculated instantly.

---

## Features

- Dark mode with navy blue, black, purple, and pink accents  
- Responsive design for mobile and desktop  
- Dynamic course input with add/remove functionality  
- Input validation for grades and credits  
- Smooth fade animations on adding/removing courses  
- User-friendly error messages and visual feedback  

---

## Technologies Used

- HTML5  
- CSS3 (with custom animations and responsive design)  
- Vanilla JavaScript (ES6+)
